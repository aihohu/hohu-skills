# HoHu Skills 文档

使用 HoHu Skills 的开发者可以从[在线安装指南](https://hohu.org/zh/guide/cli/skills)开始；维护工作流与辅助脚本的贡献者可阅读实现契约和验证指南。

| 文档 | 解决的问题 |
| --- | --- |
| [本地源码安装](installation.md) | 离线开发、上游本地源码验收及复制备用工具 |
| [工作流与辅助脚本契约](business-module.md) | 理解仓库分工、检查器结果和安装器行为 |
| [贡献指南](../CONTRIBUTING.md) | 准备改动、检查和提交 |
| [验证指南](validation.md) | 运行辅助脚本检查及设计独立项目验收 |
| [文档维护](DOCUMENTATION.md) | 确定正文归属、公开范围和检查方式 |
| [架构决策](adr/0001-portable-workflow.md) | 理解共享工作流与兼容性检查的长期取舍 |

[项目 Skill](../skills/hohu-project/SKILL.md)管理创建、初始化与运行。[业务模块 Skill](../skills/hohu-business-module/SKILL.md)及其[兼容性](../skills/hohu-business-module/references/compatibility.md)、[模块接线](../skills/hohu-business-module/references/module.md)、[AI 接入](../skills/hohu-business-module/references/ai-tools.md)、[验收流程](../skills/hohu-business-module/references/acceptance.md)是提供给编程助手的英文执行资料，随对应 Skill 一起安装。

HoHu 使用与业务开发教程统一在 [HoHu 文档站](https://hohu.org)维护，本仓库不复制教程正文。正式 Markdown 文件登记在 [公开文档清单](public-docs.txt)。
